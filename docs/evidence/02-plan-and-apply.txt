# Why West US 3, and why two stages
#
# The project defaults to Canada Central. This subscription is a free trial, and Azure would not let
# it create a Cosmos DB account in Canada Central or Canada East (the region reports
# isSubscriptionRegionAccessAllowedForRegular = false). The App Service quota API also reported zero
# B1 instances in every region that publishes a figure. West US 3 allowed both. Rather than find
# that out ten minutes into an apply, the App Service plan was created first as a probe, then the rest.
# GUIDE.md covers this case: set `location` in terraform.tfvars. The `cac` in the resource names
# is the project's naming default, not the region these resources ran in.
